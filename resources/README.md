# Video Resources Directory

This directory stores video and preview files for the InstantFlow movie database.

## Directory Structure

Each film should have its own subdirectory named by its film ID:

```
resources/
├── 1/
│   └── film.mp4
│   └── preview.jpg
├── 2/
│   └── film.mp4
│   └── preview.jpg
├── 3/
│   └── film.mp4
│   └── preview.jpg
└── ...
```

## Initial Setup

On first database setup, a small collection of sample movies is pre-populated without video files (the only one to actually have video files is the first one). To add more movies use the admin panel.
